# OpenRecall 0.3.0

يتوفر هذا الإصدار لويندوز ولينكس بمعمارية x64.

- أضف سؤالًا مقاليًا، وانسخ نصه إلى الحافظة، ثم قيّمه مباشرةً بعد مراجعتك.
- أنشئ سؤال اختيار بإجابة واحدة أو عدة إجابات مع خلط الاختيارات اختياريًا. الإجابة الصحيحة تتيح التقييمات الأربعة. الإجابة الخاطئة أو التخطي يسجّلان «نسيت»، مع التصحيح والموعد الفعلي وإمكانية التراجع.
- حرّر الأنواع الجديدة واستوردها مع المعاينة. يمكنك استخدام نوع مختلف لكل صيغة بديلة ضمن البطاقة نفسها.
- تظهر اختيارات البطاقة في سياق مجموعة الكتابة وتدخل الكلمات المؤهلة من الاختيارات الصحيحة في التجميع.
- يستعيد الإصدار نسخ 0.1.0 و0.2.0 ويصدّر نسخة كاملة بالإصدار الجديد من مخطط البيانات.
- يستخدم محدّث ويندوز نسخة من مكتبة ZIP تتضمن الإصلاحات الأمنية المنشورة.

تعمل المراجعة محليًا دون إنترنت. يظل محرك الجدولة FSRS-7 وتظل عقوبات الجدولة مفعلة افتراضيًا.
