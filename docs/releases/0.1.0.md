# OpenRecall 0.1.0

Initial offline desktop release: Arabic dark RTL UI, accessible semantic review headings, bundled multilingual fonts, native SQLite storage and the pinned FSRS-7 engine/optimizer. Variants use one logical learning state and a persisted shuffled bag with reserved presentations and no immediate repeat at a multi-form cycle boundary.

Reviews support urgency-ordered due cards, new/previous filters, live due arrivals, native interval previews, atomic idempotent rating, one-step complete undo and session summaries. Profile-scoped training includes explicit membership, minimum-data gates, chronological holdout, cancellation and stale-result rejection. Schedule Penalties default to enabled.

JSON card import includes readonly preview, validation, explicit invalid-variant exclusion and library-wide duplicate detection. Format-1 portable backup includes settings, cards/forms, scheduling/history, sessions/undo and models/jobs. Restore validates its digest and relationships, writes a safety export, and replaces the library transactionally.

Final review regressions protect cross-profile drafts and late navigation/training responses, keep exports valid after form removal, reject scheduler-incompatible restored memory, and present Arabic native recovery without replacing an unavailable library with empty data.

Updates require an explicit user request, official updater signature and signed-version verification, edit/review/job guards and a durable SQLite checkpoint. Release CI compiles without credentials, signs only during bundling, verifies every signed artifact, assembles all four updater targets and publishes only a complete draft after checking server asset digests.

Windows x64 is the primary target; normal and WebView2-inclusive offline NSIS packages are produced. Secondary build targets are Linux x64 (AppImage/deb), macOS Apple Silicon and macOS Intel. See [verification and its limits](../testing/automated-results.md), [the human NVDA checklist](../testing/human-nvda-checklist.md) and [signing custody](signing.md). No OS publisher certificate, notarization, unperformed screen-reader result or full older-version update run is claimed.

Linux retains the disclosed [upstream GLib iterator advisory](linux-glib-advisory.md). The affected crate is absent from Windows/macOS target graphs, no production iterator call site was identified, and the dependency alert remains open.
