# OpenRecall 0.1.0

الإصدار الأول من OpenRecall للمذاكرة والمراجعة دون اتصال، بواجهة عربية داكنة وأقسام مطوية افتراضيًا.

- إنشاء المجموعات والبطاقات وتعديلها وحذفها، مع إحصاءات للمجموعات وسجل المراجعة.
- جدولة FSRS-7 وصيغ بديلة عشوائية تشترك في تقدم واحد، دون تكرار الصيغ داخل الدورة.
- مراجعة البطاقات المستحقة مع فلاتر الكل والجديدة وبطاقات سبق تقييمها، وإدخال ما يستحق أثناء الجلسة، والتراجع عن آخر تقييم وملخص الجلسة.
- معاينة استيراد JSON واستبعاد البطاقات والصيغ غير الصالحة أو المكررة قبل الاستيراد.
- نماذج تحسين مستقلة أو مشتركة، وتدريب محلي يمنع النتائج غير الكافية أو القديمة. Schedule Penalties مفعلة افتراضيًا.
- نسخ احتياطي يشمل المكتبة والإعدادات والتقدم والنماذج، واستعادة بمعاينة ونسخة أمان من المكتبة السابقة.
- إعدادات متقدمة وتوقيت القاهرة وبداية يوم المذاكرة عند الواحدة صباحًا افتراضيًا، مع دعم محتوى البطاقات بلغات مختلفة.
- تحديث اختياري من داخل التطبيق، مع التحقق من توقيع الحزمة ورقم الإصدار قبل تثبيتها.

نسخة ويندوز العادية أصغر حجمًا وقد تحتاج تنزيل WebView2 إذا كان غير مثبت. نسخة ويندوز offline تتضمن مثبّت WebView2 للعمل على جهاز غير متصل. تتوفر أيضًا حزم macOS بمعماريتي Apple Silicon وIntel وحزم Linux.

اختبارات الوصول الآلية لا تغني عن الاختبار البشري بقارئ شاشة. أُرفقت قائمة لاختبار NVDA، ولم يُدَّع تنفيذها آليًا. حزم ويندوز لا تحمل شهادة ناشر تجارية، وحزم macOS غير موثّقة لدى Apple.
