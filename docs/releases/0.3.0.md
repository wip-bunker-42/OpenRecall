# OpenRecall 0.3.0

This release provides Windows x64 and Linux x64 packages.

- Add essay prompts with native copy to clipboard, optional notes and direct spaced-repetition ratings.
- Add single-answer and multiple-answer choices with optional shuffling. Correct submissions unlock all four ratings. Incorrect and skipped submissions record Again and show durable correction, the actual due time and an undo action.
- Author and preview both types in Arabic. JSON imports support per-form types and portable answer keys. Alternatives share scheduling and may use different question types.
- Retain typed source context for spelling practice. Correct choices contribute words alongside eligible prompt and notes text.
- Export and restore format 2, schema 10. Genuine 0.1.0 and 0.2.0 backups remain supported. Keep a current backup before upgrading.
- Update the Windows updater dependency to use a ZIP library version with the published fixes.

Study and local grading work offline. The pinned FSRS-7 model and default Schedule Penalties are unchanged.

The Linux packages retain the existing [upstream GLib advisory](https://github.com/wip-bunker-42/OpenRecall/blob/main/docs/releases/linux-glib-advisory.md).
